## Вариант 1. GitHub Desktop (рекомендуется)

1. Открыть **GitHub Desktop** и войти в аккаунт GitHub
   (`File → Options → Accounts → Sign in`).
2. **File → Add local repository…**
   - Local path: `C:\OSPanel\domains\localhost\illuminos`
   - Нажать **Add repository**.
3. В правом верхнем углу нажать **Publish repository**.
   - Name: `illuminos`
   - Description: `Онлайн-кинотеатр на PHP + MySQL — учебный проект ПМ.01`
   - Снять галочку **Keep this code private**, если нужен публичный репозиторий.
4. Открыть репозиторий на github.com и убедиться, что файлы загружены.

### Проверка изменения файла (требование практики)

1. Изменить файл, например `README.md` — добавить строку в конце.
2. В GitHub Desktop появится изменение на вкладке **Changes**.
3. Ввести сообщение коммита и нажать **Commit to master**.
4. Нажать **Push origin**.
5. На сайте GitHub открыть `README.md` — изменение видно.
   Вкладка **History** покажет коммит.

## Размер репозитория и «лёгкая» публикация

Текущее дерево проекта без видео занимает около **23 МБ** (включая скриншоты
и дамп БД). Однако в **истории** git остались старые коммиты с демо-видео
(`assets/video`, около 100 МБ). При обычном `git push` они тоже уйдут на GitHub.

Вариант A — публиковать как есть: сайт останется с видео в истории,
первая загрузка займёт несколько минут.

Вариант B — опубликовать один чистый коммит без истории видео
(локальная ветка `master` при этом сохраняется):

```bash
git checkout --orphan release
git add -A
git commit -m "Illuminos: учебный проект ПМ.01"
git push -u origin release:main
git checkout master
```

На GitHub ветка `main` будет содержать только актуальные файлы без видео.
Видеофайлы останутся на диске локально (они в `.gitignore`).

Вариант C — переписать историю (`git filter-repo` / `git filter-branch`)
удаляет старые коммиты безвозвратно, выполнять только при необходимости
и после резервной копии.

## Проверка после публикации

| Что проверить | Ожидаемый результат |
|---|---|
| Страница репозитория на GitHub | Видны папки `admin/`, `assets/`, `database/`, `docs/` |
| README.md | Описание, стек, установка, схема БД, скриншоты |
| История коммитов | Не менее двух коммитов |
| Изменение файла | После commit + push новая строка видна на GitHub |
| GitHub Desktop | Изменение появляется на вкладке Changes |

## Важно для проверяющего

- В репозиторий **не попадают** загруженные пользователями файлы
  (`uploads/avatars`, `uploads/posters`) — исключены через `.gitignore`.
- Паролей и ключей в репозитории нет: в `config/db.php` только локальные
  настройки OpenServer Panel (root без пароля).
- Дамп базы `database/db.sql` (схема + данные, utf8mb4) включён в репозиторий.
- Демо-видео в репозиторий не коммитятся, но остаются на диске для работы сайта.
- Скриншоты страниц — в `docs/screenshots/`, используются в README.
