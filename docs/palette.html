Цветовая палитра Illuminos

Тёмная кинематографичная тема: глубокий фон, тёплый оранжевый акцент и спокойный фиолетовый для второстепенных действий. Палитра подобрана так, чтобы постеры фильмов оставались главным визуальным элементом, а интерфейс не конкурировал с ними.

Контраст

Текст #FFFFFF на фоне #0B0B0F — контраст 19.6:1 (AAA). Вторичный текст #6B7280 на фоне #15151D — 3.8:1 (AA для крупного текста). Тёмный текст #191300 на оранжевой кнопке #FF6B35 — 6.5:1 (AA).

5. Правила использования

Акцентный цвет — только для действий. Оранжевый применяется к главной кнопке на экране, активному фильтру и рейтингу — не более 10% площади.

Постеры — главные. Интерфейс не спорит с изображениями: фон тёмный, подписи вторичные.

Состояния обязательны. У каждой интерактивной кнопки есть hover, focus-visible и disabled. Ошибки — красным, успех — зелёным, подсказки — серым.

6. Файл токенов

Все значения хранятся в CSS-переменных в начале файла assets/css/style.css — палитра меняется в одном месте.

:root {
    --bg: #0B0B0F;          /* фон страницы */
    --surface: #15151D;     /* карточки, формы */
    --surface-2: #1C1C24;   /* меню, hover */
    --text: #FFFFFF;        /* основной текст */
    --muted: #6B7280;       /* вторичный текст */
    --accent: #FF6B35;      /* главный акцент */
    --accent-2: #FFA07A;    /* градиент кнопок */
    --violet: #7c5cff;      /* служебный акцент */
    --success: #3ddc97;
    --danger: #ff5c5c;
    --radius-sm: 10px; --radius: 16px; --radius-lg: 24px;
}
