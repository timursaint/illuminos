## 3. Найденные и устранённые дефекты

| № | Дефект | Причина | Исправление |
|---|---|---|---|
| 1 | Живой поиск возвращал HTTP 500 | Один и тот же именованный параметр `:q` использован 4 раза при `EMULATE_PREPARES = false` | Уникальные параметры `:q1…:q4` в `api/search.php` |
| 2 | Логотип hero выходил за левый край, контент прилипал к краю | `padding: 96px 0 40px` у `.hero__inner` сбрасывал боковые отступы `.container`; логотип не был ограничен по ширине | Горизонтальные отступы вынесены в `.container`, добавлены `max-width: min(460px, 100%)` для логотипа |
| 3 | Фатальная ошибка на главной у авторизованного пользователя | В `recommendations_for()` параметр `:u` повторялся в трёх подзапросах | Разделены на `:fav`, `:hist`, `:watched`, `:faved` |
| 4 | Страница категорий в админке — `Call to undefined function genres_all()` | Не подключён `includes/catalog.php` | Добавлен `require_once` |
| 5 | Дубль названия в hero (логотип + заголовок) | Заголовок выводился всегда | Заголовок скрывается классом `.sr-only`, если есть PNG-логотип |
| 6 | Старые стили после правок | Кэш браузера | Версионирование CSS/JS через `asset_versioned()` |
| 7 | Поиск в каталоге и админке — HTTP 500 (`Invalid parameter number`) | Повтор параметра `:q` в `search_titles()`, `admin/users.php`, `admin/payments.php` при `EMULATE_PREPARES = false` | Уникальные параметры `:q1…:q4` / `:q1…:q3` |
| 8 | Ссылки на жанры в карточке тайтла давали 0 результатов | В ссылку подставлялось русское название вместо slug (`?genre=боевик` вместо `?genre=action`) | `title_genres_map()` возвращает `name` + `slug`, ссылка строится по slug |
| 9 | В блоке «Похожие сериалы» выводились фильмы | `similar_titles()` не фильтровал по типу | Добавлено условие `t.type = :type` |
| 10 | Фатальная ошибка в кабинете и на главной у авторизованного | `GROUP BY t.id` при выборке `h.progress` и `ONLY_FULL_GROUP_BY` | Последняя запись истории выбирается подзапросом `MAX(id)` |
| 11 | Формы входа и регистрации принимали POST без CSRF-токена | Токен не выводился в `login.php`, `register.php` и модальных окнах | Добавлены `csrf_field()` и серверная проверка `csrf_valid()` (AJAX → 403) |
| 12 | Категории каталога были доступны только по `?genre=` | В ссылках использовался устаревший параметр | Основной параметр `?category=`, `?genre=` оставлен как алиас |

После исправлений повторно пройдены проверки № 1, 7, 8, 14, 63–67 — дефекты не воспроизводятся.
